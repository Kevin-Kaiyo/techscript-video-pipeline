# Repository Structure

This file describes the current public repository shape. Historical EP01 scripts are kept under `archive/` and are not the primary workflow.

```text
techscript-video-pipeline/
├── archive/
│   └── legacy_ep01/                 # Previous static-image EP01 scripts
├── docs/
│   ├── ARCHITECTURE.md              # System architecture
│   ├── WORKFLOW.md                  # Current episode workflow
│   ├── SETUP.md                     # Environment setup
│   ├── SETUP_COSYVOICE.md           # Optional local CosyVoice setup
│   └── PROJECT_AUDIT_2026-05-18.md  # Stabilization audit
├── episodes/
│   ├── demo-industry/               # HyperFrames reference demo
│   ├── demo-data/                   # HyperFrames data/chart demo
│   ├── demo-tech/                   # Temporary technical HyperFrames demo
│   ├── demo-manim/                  # Manim Micro LED mass-transfer demo
│   └── ep01/                        # Original Micro LED episode material
├── pipeline/
│   ├── tts/                         # TTS provider abstraction
│   ├── manim/                       # Manim scenes and helpers
│   ├── tts_cli.py                   # Unified TTS CLI
│   ├── auto_schedule.mjs            # Voiceover duration -> schedule
│   ├── preflight.mjs                # Build preflight checks
│   ├── render_cdp_resumable.mjs     # Chrome CDP frame renderer
│   ├── compose_audio.mjs            # FFmpeg audio mix
│   ├── build_episode.sh             # HyperFrames end-to-end build
│   └── build_manim_episode.sh       # Manim render + audio mix
├── shared/
│   └── brand/
│       ├── brand.json               # Visual identity tokens
│       ├── tts.json                 # TTS preferences
│       └── video.json               # Video defaults
├── voices/
│   └── kevin/
│       ├── README.md
│       └── prompt_text.txt          # Text only; raw voice sample is ignored
├── package.json                     # Node dependencies and smoke checks
├── requirements-tts.txt             # Python TTS dependencies
├── Makefile
├── README.md
├── PROJECT.md
├── NOTICE
└── LICENSE
```

## Episode Contract

Each reusable episode should follow this layout:

```text
episodes/<ep>/
├── script.md
├── audio_schedule.json              # Generated by auto_schedule.mjs
├── animations/
│   └── hyperframes/
│       └── index.html
├── audio/
│   └── voiceover/                   # Generated locally, ignored by git
├── subtitles/                       # Optional
└── output/                          # Generated locally, ignored by git
```

## Stable vs Historical

- Stable path: `pipeline/tts_cli.py`, `pipeline/auto_schedule.mjs`, `pipeline/build_episode.sh`, and HyperFrames episode directories.
- Manim path: `pipeline/manim/` plus `pipeline/build_manim_episode.sh`.
- Historical path: `archive/legacy_ep01/`. Keep it for reference, but do not present it as the main pipeline.
